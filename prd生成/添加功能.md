# DAWdex 功能池与优先级

> 本文是功能 Backlog。P0 之外的功能不能阻塞 2026-07-26 黑客松 Demo。

## P0：完整体验链

### 弹幕舞台

- 全屏弹幕遮罩；
- 用户输入立即飘过；
- 弹幕不阻断核心控件；
- 真人、预设和 AI 乐迷来源可区分；
- 基础内容过滤。

### 音乐意图编译

- 转写纠错；
- 无意义乱码拒绝；
- 制作人选择意见；
- 输出 `MusicBrief`；
- 输出 Drums/Bass/Keys 三个 `RoleTask`；
- 角色专业术语带通俗解释；
- 角色对话从真实任务生成。

### 音乐执行

- 固定 BPM、调性和 4 小节循环；
- 至少三条可编辑 MIDI；
- 三个角色依次加入；
- 加入点与角色动画同步；
- 一次 Undo；
- 模型失败时本地回退。

### Demo

- 固定 Prompt；
- 固定安全工程；
- 90 秒脚本；
- 断网演示；
- 预录视频；
- 提交截图和 README。

## P1：增强创意

### 多弹幕

- 去重；
- 语义聚类；
- 共识统计；
- 相关性、共识、可行性、新颖性和连续性评分；
- 制作人解释采用理由。

### AI 乐迷

- 根据真人意见产生不同立场的附和或补充；
- 使用独立头像与“AI”标签；
- 不冒充真人数量；
- 可关闭；
- 不直接影响音乐，仍由制作人裁决。

### MIDI 素材库

- 元数据索引；
- 风格、情绪、角色、BPM、Key、Bars、Energy；
- 加权检索；
- 移调；
- 裁剪和循环；
- 音域适配；
- 力度变体；
- 第四小节变化；
- 变换 Receipt。

### Provider

- OpenAI；
- 千问；
- 自定义 OpenAI-compatible；
- 连接测试；
- 模型选择；
- 安全保存 Key。

## P2：比赛后

- 真正独立的多 Agent；
- Codex CLI；
- Claude Code CLI；
- Qwen Code/OpenCode；
- 完整混音师；
- 主奏和更多乐器；
- 音符级角色动画；
- Electron 打包；
- 专业模式；
- 导出标准 MIDI/Project Blueprint；
- 真实 B 站或直播弹幕；
- 远程多人房间。

## 质量功能

硬校验：

- BPM；
- 调性；
- 拍号；
- Clip 长度；
- 音符范围；
- 乐器音域；
- Velocity；
- 新轨循环边界；
- 最大轨道数；
- 最大默认音量。

软校验：

- 意图一致性；
- 风格一致性；
- 轨道互补；
- 重复度；
- 循环结尾；
- 能量变化。

## 暂不实现

- VST Hosting；
- 完整专业 DAW；
- 自训练音乐大模型；
- 直接生成最终音频；
- 任意 Shell 工具；
- 无限制模型写工程；
- 未标记的虚拟真人弹幕；
- 未授权 MIDI 素材公开上传。

## 功能验收模板

每个功能必须回答：

```text
用户能看到什么？
用户能听到什么？
真实数据是什么？
失败时发生什么？
如何验证？
是否影响 90 秒主链？
```

如果只能回答“看起来像完成”，不能进入 P0。
